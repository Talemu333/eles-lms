# ELES LMS Frontend

React + Vite frontend for the Early Learning Services LMS, based directly on the supplied ELES LMS HTML design.

## Run locally

```bash
git pull origin main
npm install
npm run dev
```

If this is a fresh local checkout:

```bash
git clone https://github.com/Talemu333/eles-lms.git
cd eles-lms
npm install
npm run dev
```

The current frontend keeps the supplied localStorage/sessionStorage behavior so the interface can be tested before the MySQL backend is wired in. Backend/API integration is intentionally left for the next phase.
